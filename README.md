# tg_suf — Ручной диктор

Персональный аудиодиктор Telegram-каналов. Проект на стадии разработки; см. [спецификацию в Notion](https://app.notion.com/p/3fe043746cc681cf91aef9c1020f4876).

Доступ к постам предоставляется только через пользовательскую Telegram MTProto-сессию; бот Telegram не читает личные подписки.
