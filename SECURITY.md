# Безопасность проекта tg_suf

Это локальный прототип чтения Telegram-каналов с пользовательской авторизацией MTProto.

## Секреты

- Никогда не коммитьте `.env`, `.local/`, `*.session`, `*.session-journal`, `api_hash`, коды Telegram и пароль двухэтапной аутентификации.
- Не отправляйте файл сессии Telegram в Issues, Pull Requests или логи CI. Утраченную сессию завершите в настройках устройств Telegram.
- Используйте собственные `api_id` и `api_hash`; не делитесь ими.

## Сеть

- Текущий HTTP-плеер предназначен **только** для `127.0.0.1`. Не публикуйте порт через туннели, reverse proxy или открытый интерфейс сети: у прототипа нет внешней аутентификации.
- Не используйте проект для выгрузки или публикации чужого контента. Учитывайте ограничения Telegram API и защищённых публикаций.

## Сообщения об уязвимостях

Не размещайте в публичных Issues учётные данные, токены, персональные данные или тексты закрытых каналов. Используйте приватный канал связи с владельцем репозитория.
